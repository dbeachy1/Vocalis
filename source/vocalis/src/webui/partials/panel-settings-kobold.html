KoboldCpp

Only needed if you run KoboldCpp and want to load and unload its models from Vocalis. Leave this blank otherwise — nothing else in Vocalis uses it, and the KoboldCpp tab is the only thing affected.
The URL and the password are a pair — the password is scoped to that URL and means nothing without it. It's the --adminpassword KoboldCpp was started with. Set once; you are never prompted again. Saving tests the connection. (VOCALIS_KOBOLD_URL / VOCALIS_KOBOLD_ADMINPASSWORD override these.)
KoboldCpp must listen on more than loopback (start it with --host 0.0.0.0, or the machine's LAN address), and 127.0.0.1 here would be this container itself, so use host.docker.internal for a KoboldCpp on this machine.
—
A KoboldCpp model wants whole cards, and every card ticked in Devices above can be holding a Vocalis model. Load on the KoboldCpp tab asks first and names the cards that are still ticked — it never refuses, and unticking them is what actually frees the memory. Only applies when KoboldCpp is on this machine: a model loading on another box is not sharing these cards. Turn the warning off, for this and for the reverse direction, with Warn me if I enable a device… under Devices above.
