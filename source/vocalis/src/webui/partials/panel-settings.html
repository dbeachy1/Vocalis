Devices

Where speech is rendered — Book, Playground, Nomi and SillyTavern all use the devices ticked here. Tick a device to use it. Saved automatically. Each ticked device holds one copy of the model — a second copy on the same card measured slower, not faster. Satellite cards appear when that machine is running — this list re-checks every 10 seconds while you are on this tab.

Covers both directions of the same collision: ticking a device here while KoboldCpp or llama.cpp is holding this box's cards, and pressing Load on either of those tabs while a device here is ticked. Always a warning that names what is in the way, never a refusal — sharing a card is your call. It says nothing when the engine is on another machine, because those are not these cards.
A worker is one copy of the model. 1 leaves VRAM headroom for co-tenant LLMs (SillyTavern); 2 costs ~+4 GB on that card and lets one worker's CPU work overlap another's GPU work — how much that is worth depends on the card and has not been measured here. Each device is set separately — a 24 GB satellite card and a card sharing a box with an LLM do not want the same number.
Speech only. Enhancing and voice creation never run on a satellite — the enhancer wants a whole card to itself and about 21 GB of it, which would evict the very rendering you moved there. They use this machine's own ticked cards, so unticking all of them switches those two features off as well.

Appearance

16 px
Scales every piece of text in Vocalis. 16 px is the browser default and the standard size for body text — below about 14 it starts to be hard to read at 100% zoom. Images, waveforms and charts are not scaled, so turning this up buys readability without costing screen space, which is the difference from browser zoom. Applies as you drag.

SillyTavern extension

Needed for SillyTavern narration, and to push worldbooks and character cards back into SillyTavern. Importing and exporting files works without it.
The extension runs inside your already logged-in SillyTavern session, so Vocalis never stores a SillyTavern password. This token is how the extension proves it is yours — Vocalis's own login cookie cannot reach it, because the browser will not send a cookie from SillyTavern's address to this one. Paste it into the Vocalis extension's settings in SillyTavern once. Generating a new one immediately stops the old one working.

Nomi extension

Required to play Nomi replies through Vocalis. Until 7.2 this channel was open: anyone who could reach this server could use your GPU to generate speech, and could add entries to the Nomi voice map. The token is how the Chrome extension proves it is yours. Generating a new one immediately stops the old one working.
Separate from the SillyTavern token above — they rotate independently, and pasting the wrong one fails exactly like pasting none. Get the extension itself from the Nomi tab, then paste this into its Options page.

Admin login

Gates Vocalis Studio — the whole web app. The Nomi and SillyTavern extensions do not use this login; each has its own pairing token, above. Forgot the password? Use your recovery key on the login page. (An install without encryption has no recovery key; there, run scripts/set-admin-credentials on the server.)
🔑 This is also your encryption password. It authenticates you and unlocks the vault — logging in is what unwraps the key. Changing it here re-wraps the key at the same time, which is why the current password is required. Removing the login is not possible while encryption is on: a vault with no login can never be unlocked.

Recovery key

The recovery key is the only way back into your data if you forget your password — it unlocks the vault and sets a new password in one step. Generating a new one immediately revokes the old one. Your password and your data are untouched, and you stay logged in.
⚠️ Older vault_keys.yaml backups still answer to the old key. If you are rotating because a key may have leaked, replace those backups too.
