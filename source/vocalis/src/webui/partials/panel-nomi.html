Chrome extension

Plays Nomi replies through Vocalis. Chrome doesn't allow installing an extension from a web page, so it's a one-time manual load:
  1. Download below and unzip somewhere permanent — Chrome keeps loading it from that folder, so don't delete it.
  2. Open chrome://extensions and turn on Developer mode (top-right toggle).
  3. Click Load unpacked and pick the unzipped vocalis-tts-for-nomi folder.
  4. Right-click the extension's icon ▸ Options and set the server URL to the address you open Vocalis at (the one in this page's address bar, without the path).
  5. Paste the pairing token into that same Options page — it is in ⚙ Settings ▸ Nomi extension. Without it Vocalis refuses to speak.
  6. To update later: download again, replace the folder's contents, then hit ↻ on chrome://extensions.

Nomi voice map

Map each Nomi (by ID) to a voice for the Chrome extension's /speak. Play a Nomi in the extension and its card appears here automatically with the name filled in — pick a voice and Save. The knobs are that Nomi's own delivery settings — exactly what /speak uses. ▶ Audition renders the on-screen values without saving; only Save persists.
