Vocalis TTS for Nomi

Plays Nomi replies through your local Vocalis server (Chatterbox TTS). This is where messages are sent to be spoken (/speak).

Local (same machine): the address you open Vocalis at, for example http://127.0.0.1:18770 for the Docker package or http://127.0.0.1:7870 for a Vocalis started directly.
Over the LAN with HTTPS: https://your-server:7870 — the browser must trust that server's certificate.
The port must be the one Vocalis answers on; change it here if you chose another at setup.
No trailing slash. A non-localhost address must be https:// — browsers block plain-HTTP requests from the nomi.ai page.
Required. Vocalis refuses /speak without it — otherwise anyone who can reach your server could use your GPU and add entries to your Nomi list.
Get it in the Vocalis web UI: ⚙ Settings ▸ Nomi extension ▸ Copy. It is a different token from the SillyTavern one — they rotate independently, so pasting the wrong one will not work.
Rotating it in Vocalis revokes this copy immediately; paste the new value here to pair again.
